# Identity Card Application

## English

A C# Windows Forms application for entering and saving identity card information.

- Photo upload and card preview
- Name, FIN, and date validation
- Save information as XML
- Clear all fields

Open `identitycardaze.sln` in Visual Studio and press `F5`.

Requires Windows and .NET Framework 4.8.

- Ad, FİN və tarixlərin yoxlanılması
- Məlumatların XML kimi saxlanılması
